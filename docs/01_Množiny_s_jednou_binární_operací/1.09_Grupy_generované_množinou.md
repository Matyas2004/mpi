<a id="def-1.13"></a>
!!! Definition "[Definice 1.13 (Grupa generovaná podmnožinou)](#def-1.13)"

    ### Grupa generovaná podmnožinou {#def-1.13}
    Nechť $G = (M, \circ)$ je grupa a $N \subseteq G$ je neprázdná množina. Podgrupu

    $$\langle N \rangle := \bigcap\{H | H \text{ je podgrupa grupy } G \text{ obsahující } N \} $$

    nazýváme **podgrupou generovanou množinou $N$**. Množinu $N$ pak nazýváme **generující množinou** grupy $\langle N \rangle$

<a id="def-1.14"></a>
!!! Definition "[Definice 1.14 (Generátor)](#def-1.14)"

    ### Generátor {#def-1.14}
    
    Pro jednoprvkovou [generující množinu](#def-1.13) $N=\{a\}$ zavádíme značení $\langle a \rangle := \langle \{a\} \rangle$.
    V tomto případě o $a$ mluvíme jako o **generátoru** grupy $\langle a \rangle$.

<a id="theorem-1.14"></a>
!!! Theorem "[Věta 1.14 (Korektnost definice)](#theorem-1.14)"

    ### Věta 1.14 (Korektnost definice) {#theorem-1.13}

    Buď $G = (M, \circ)$ grupa a $N \subseteq G$ neprázdná množina. Pak $G' = (\langle N \rangle , \circ)$ je podgrupou
    grupy $G$ obsahující množinu N.

??? proof "Důkaz věty 1.13"

    $\langle N \rangle$ je grupa dle [věty 1.9](1.07_Podgrupy.md#theorem-1.9) o průniku grup.
    <br>
    <br>

    Každá z grup $H$ dle definice $\langle N \rangle$ obsahuje $N$, a proto i průnik všech těchto grup, tj. $\langle N \rangle$ obsahuje $N$.


$\langle N \rangle$ je nejmenší podgrupa grupy $G$ obsahující množinu $N$. Z kontextu musí být čtenáři
jasné, o jaké grupě se bavíme (v notaci $\langle N \rangle$ je to potlačeno)

<a id="exc-1.11"></a>
!!! example "[Příklad 1.11 (Grupa $\mathbb{Z}_{12}^+$)](#exc-1.11)"

    V grupě $\mathbb{Z}_{12}^+$ je $\langle 2 \rangle = (\{0, 2, 4, 6, 8, 10\}, +_{12})$ (viz [Příklad 1.10](1.07_Podgrupy.md#exc-1.10))


<a id="exc-1.12"></a>
!!! example "[Příklad 1.12 (Grupa $\mathbb{Z}_{12}^+$ podruhé)](#exc-1.12)"

    Grupa $\mathbb{Z}_{12}^+$ je generována např. množinami $\{1\}$ a $\{5\}$. Prvky 1 i 5 jsou generátory $\mathbb{Z}_{12}^+$.
    (viz [Příklad 1.10](1.07_Podgrupy.md#exc-1.10))


<a id="theorem-1.15"></a>
!!! Theorem "[Věta 1.15 ("Grupový obal")](#theorem-1.15)"

    ### Věta 1.15 ("Grupový obal") {#theorem-1.15}

    Buď $G = (M, \circ)$ grupa a $N \subseteq M$ neprázdná množina. Potom všechny prvky patřící do $\langle N \rangle$ lze získat
    pomocí ”grupového obalu“

    $$\langle N \rangle = \left\{a_1^{k_1} \circ a_2^{k_2} \circ \dots \circ a_n^{k_n} | n \in \mathbb{N}, k_i \in \mathbb{Z}, a_i \in N\right\}$$
