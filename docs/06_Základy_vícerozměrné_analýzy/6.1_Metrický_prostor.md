!!! Definition "[Definice 6.1 (Metrický prostor)](#def-6.1)"

    ### Definice 6.1 (Metrický prostor) {#def-6.1}

    **Metrický prostor** je dvojice $(X, d)$, kde $X$ je neprázdná množina a $d: X \times X \to \mathbb{R}^+_0$ je zobrazení,
    které se nazývá **metrika** (metric) na $X$ a pro všechna $x, y, z \in X$ splňuje:

    1. $d(x,y) \ge 0 \wedge d(x, y) = 0 \Leftrightarrow x = y$ (vzdálenost je nulová právě tehdy, když jde o jeden a týž bod),
    2. $d(x, y) = d(y, x)$ (symetrie),
    3. $d(x, z) \le d(x, y) + d(y, z)$ (trojúhelníková nerovnost)

<a id="note-6.1"></a>
!!! Implication "[Poznámka 6.1 (Podobnost normy a metriky)](#note-6.1)"

    ### Poznámka 6.1 (Podobnost normy a metriky) {#note-6.1}

    Zvídavý čtenář si jistě všimne podobnosti mezi [normou](../05_Mocninná_metoda/5.3_Norma.md#def-5.8)
    a metrikou. Platí dokonce, že metrika definovaná pomocí normy jako: $d(\m{x}, \m{y}) = \| \m{x} - \m{y} \|$ 
    je skutečně metrikou nad stejným prostorem.

<a id="ex-6.1"></a>
!!! example "[Příklad 6.1 (Příklady metrik)](#ex-6.1)"

    ### Příklad 6.1 (Příklady metrik) {#ex-6.1}

    - Pro neprázdnou množinu $X$ je $(X, d)$ metrický prostor, kde $d(x, y) = 1$ pro $x \neq y$ a $d(x, x) = 0$.
    - Hammingova vzdálenost na množině všech binárních řetězců délky $n$ je metrika.
    - Zobrazení $d(x, y) = |x − y|$ je metrika na $\mathbb{R}$.
    - Eukleidovská vzdálenost na $\mathbb{R}^n$ je metrika.
    - Spojité funkce $C[a, b]$ s metrikou $d(f, g) = \max_{x\in[a,b]} |f(x) − g(x)|$.

<a id="def-6.2"></a>
!!! Definition "[Definice 6.2 (Otevřená koule (open ball))](#def-6.2)"

    ### Definice 6.2 (Otevřená koule (open ball)) {#def-6.2}

    Buď $(X,d)$ metrický prostor, $x \in X$ a $\delta \in \mathbb{R}^+$.

    **Otevřená koule o středu $x$ a poloměru $\delta$** je množina

    $$B_\delta(x) = \{ y \in X | d(x,y) < \delta \}$$

    Množině $B_\delta(x)$ říkáme také **$\delta$-okolí bodu $x$** ($\delta$-neighborhood)

<a id="ex-6.2"></a>
!!! example "[Příklad 6.2 (Příklady otevřených koulí)](#ex-6.2)"

    ### Příklad 6.2 (Příklady otevřených koulí) {#ex-6.2}

    - V $\mathbb{R}$ s metrikou $d(x, y) = |x − y|$ je $B_\delta(x) = (x − \delta, x + \delta)$.
    - V $\mathbb{R}^2$ s eukleidovskou metrikou je $B_\delta(x)$ kruh bez hraniční kružnice.
    - V prostoru s metrikou $d(x, y) = 1$ pro $x \neq y$ je $B_1(x) = \{x\}$ a $B_2(x) = X$.
    - V $C[a, b]$ s maximovou metrikou je $B_\delta(f)$ množina všech spojitých $g$, 
    jejichž graf leží v „pásu“ šířky $2\delta$ kolem grafu $f$.

<a id="def-6.3"></a>
!!! Definition "[Definice 6.3 (Metrický podprostor (metric subspace))](#def-6.3)"

    ### Definice 6.3 (Metrický podprostor (metric subspace)) {#def-6.3}

    Buď $(X, d)$ metrický prostor a $\emptyset \neq Y \subseteq X$.  

    **Metrický podprostor** prostoru $(X, d)$ je metrický prostor $(Y, d_Y)$, kde $d_Y$ je zúžení
    metriky $d$ na $Y$, tj.

    $$d_Y(x, y) = d(x, y) \quad \text{pro všechna } x, y \in Y$$

<a id="ex-6.3"></a>
!!! example "[Příklad 6.3 (Příklady metrických podprostorů)](#ex-6.3)"

    ### Příklad 6.3 (Příklady metrických podprostorů) {#ex-6.3}

    - Interval $[a, b]$ s metrikou $d(x, y) = |x − y|$ je podprostorem $\mathbb{R}$.
    - Jednotková kružnice $\{\m{x} \in \mathbb{R}^2 : \|\m{x}\|_2 = 1\}$ s eukleidovskou metrikou je podprostorem $\mathbb{R}^2$.
    - Množina $\mathbb{Z}$ s metrikou $|x − y|$ je podprostorem $\mathbb{R}$
        - platí $B_1(x) = {x}$ pro $x \in \mathbb{Z}$, zatímco v $\mathbb{R}$ je $B_1(x) = (x − 1, x + 1)$.
