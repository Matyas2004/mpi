<a id="def-2.1"></a>
!!! Definition "[Definice 2.1 (Homomorfismus)](#def-2.1)"

    ### Definice 2.1 (Homomorfismus) {#def-2.1}
    
    Buďte $G = (M, \circ_G)$ a $H = (N, \circ_H)$ dva grupoidy. Zobrazení $h : M \to N$ nazveme homomorfismem $G$
    do $H$ jestliže

    $$\text{pro všechna } x, y \in M \text{ platí } h(x \circ_G y) = h(x) \circ_H h(y)$$

    - Je-li navíc $h$ **injektivní**, pak ho nazýváme **monomorfismus** 
    - Je-li $h$ **surjektivní**, pak **epimorfismus** 
    - A v neposlední řadě, je-li $h$ **bijektivní**, pak **izomorfismus**.

- Homomorfismus tedy zachovává strukturu danou binární operací: je jedno jestli nejdříve aplikuji operaci a pak homomorfismus, nebo naopak.
- Definice se přímo přenáší na grupy, a používá se termín (homo|mono|epi|izo)morfismus grup

<a id="def-2.2"></a>
!!! Definition "[Definice 2.2 (Izomorfní grupy)](#def-2.2)"

    ### Definice 2.2 (Izomorfní grupy) {#def-2.2}

    Grupy $G$ a $H$ nazýváme **izomorfní**, právě když existuje izomorfismus $G \to H$. 
    O grupě $G$ také říkáme, že je **izomorfní** s grupou $H$.

<a id="fact-2.1"></a>
!!! Theorem "[Fakt 2.1 (Ekvivalence)](#fact-2.1)"

    ### Fakt 2.1 (Ekvivalence) {#fact-2.1}

    Vlastnost dvou grup ”být izomorfní“ je relace ekvivalence na třídě všech grup.

- Příkladem izomorfních grup jsou $\mathbb{Z}_{5}^\times$ a $\mathbb{Z}_{4}^+$ 
- Je jasné, že izomorfní grupy musí mít stejný řád!

<a id="theorem-2.1"></a>
!!! Theorem "[Věta 2.1 (Homomorfismus grupy)](#theorem-2.1)"

    ### Věta 2.1 (Homomorfismus grupy) {#theorem-2.1}

    Buď $h$ homomorfismus grupy $G = (M, \circ_G)$ do grupoidu $H = (N, \circ_H)$. 
    Potom $h(G) := (h(M), \circ_H)$ je grupa.

??? proof "Důkaz věty 2.1"

    Ukážeme postupně že v $h(G)$ platí asoc. zákon, existuje neutrální prvek a každý prvek má inverzi.
    Nejprve uveďme,že každý prvek $h(G)$ lze napsat jako $h(x)$ pro nějaké vhodné $x$.<br><br>
    **Asociativita:**
    
    Pro všechna $x,y,z \in M$ platí:
    
    $$(h(x) \circ_H h(y)) \circ_H h(z) = h(x \circ_G y) \circ_H h(z) = h((x \circ_G y) \circ_G z)
        = h(x \circ_G (y \circ_G z)) = h(x) \circ_H h(y \circ_G z) = h(x) \circ_H (h(y) \circ_H h(z))$$

    **Neutrální prvek:**

    Nechť $e$ je neutrální prvek v $G$. Potom pro všechna $x$ platí $h(e) \circ_H h(x) = h(e \circ_G x) = h(x)$ (a obdobně z druhé strany).
    $h(e)$ je tedy neutrálním prvkem.<br><br>
    **Inverzní prvky**

    Obdobně ukážeme existenci inverzních prvků: $h(x) \circ_H h(x^{-1}) = h(x \circ_G x^{-1}) = h(e)$ (a obdobně z druhé strany).
    Inverzí k $h(x)$ je tedy $h(x^{-1})$.<br><br>

    Tím je důkaz dokončen, ukázali jsme, že $H$ je grupa.

<a id="implication-2.1"></a>
!!! implication "[Důsledky 2.1 (Důsledky věty 2.1)](#implication-2.1)"

    ### Důsledky 2.1 (Důsledky věty 2.1) {#implication-2.1}

    Je-li $H$ grupa, pak:

    - Neutrální prvek jedné grupy se homomorfismem zobrazí vždy na neutrální prvek té druhé grupy.
    - Také inverze se zachovávají v následujícím smyslu: $h(x^{−1}) = h(x)^{−1}$
    - Je-li $h$ homomorfismus grupy $G$ do $H$, pak $h(G)$ je podgrupa v $H$

- Například Např. $h(n) = 2n$ je homomorfismus grupy $\mathbb{Z}^+_4$ do $\mathbb{Z}^+_8$ a $h(\mathbb{Z}^+_4)$ je podgrupa $\{0, 2, 4, 6\}$.
