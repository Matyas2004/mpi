Izomorfismus $\varphi : G → H$ je ”přejmenování“ prvků, které zachovává strukturu. Z předchozích
vět, důsledků a z definice izomorfismu plyne, co všechno se při něm nemění:

- **Neutrální prvek**: $\varphi(e_G) = e_H$
- **Inverze**: $\varphi(x{−1}) = \varphi(x)^{−1}$
- **Řády prvků**: z $\varphi(x)^k = \varphi(x^k)$ a bijektivnosti $\varphi$ plyne $\text{ord } \varphi(x) = \text{ord } x$
- **Podgrupy**: obraz $h(G)$ je podgrupou v $H$ a omezení izomorfismu na podgrupu je zase izomorfismus
- Dále také cykličnost, komutativita, řád grupy, …

Tudíž: cokoli, co lze vyjádřit v jazyce teorie grup, mají izomorfní grupy společné – a právě proto říkáme,
že jsou ”totožné až na izomorfismus“

<a id="theorem-2.2"></a>
!!! Theorem "[Věta 2.2 (Izomorfismus cyklických grup)](#theorem-2.2)"

    ### Věta 2.2 (Izomorfismus cyklických grup) {#theorem-2.2}

    Libovolné dvě cyklické grupy mající stejný řád jsou izomorfní.

??? proof "Důkaz věty 2.2"

    Mějme grupu $G = \langle a \rangle$ cyklická grupa s generátorem $a$.

    Ukážeme, že libovolná nekonečná grupa je izomorfní s grupou $(\mathbb{Z}, +)$ a že libovolná cyklická
    grupa řádu $n$ je izomorfní s $\mathbb{Z}_n^+$. Zbytek už plyne z tranzitivity relace "být izomorfní".

    Hledaným izomorfismem je pak **bijekce** (ze $\mathbb{Z}$, případně $\mathbb{Z}_n^+$ na G) definovaná pro všechna
    $k$ jako $h(k) = a^k$. Toto zobrazení je skutečně homomorfismem:

    $$(\forall x,y \in \mathbb{Z}) \left(h(x) + h(y) = a^x \circ a^y = a^{x+y} = h(x+y)\right)$$

    Vzhledem k tomu, že je bijekcí, je tedy i izomorfismem.

Izomorfní grupy jsou vlastně totožné, liší se pouze pojmenováním prvků. Řekneme-li, že existuje pouze jedna grupa 
s jistou vlastností **až na izomorfismus**, znamená to, že všechny grupy s touto jistou vlastností 
jsou navzájem izomorfní. Ukážeme si tři známá tvrzení tohoto typu.

Např. $(\mathbb{Z}, +)$, a $\mathbb{Z}_n^+$ jsou jedinými cyklickými grupami **až na izomorfismus**.

<a id="def-2.3"></a>
!!! Definition "[Definice 2.3 (Kleinova grupa)](#def-2.3)"

    ### Definice 2.3 (Kleinova grupa) {#def-2.3}

    Kleinova grupa je grupa ($\mathbb{Z}_2 \times \mathbb{Z}_2, \circ$), kde:

    $$\mathbb{Z}_2 \times \mathbb{Z}_2 = \{(0,0), (0,1), (1,0), (1,1)\}$$

    a $\circ$ je sčítání modulo 2 po složkách.

Kleinova grupa není cyklická a tedy nemůže být izomorfní se $\mathbb{Z}_4^+$! 
Kleinova grupa je izomorfní $\mathbb{Z}_8^\times$


<a id="theorem-2.3"></a>
!!! Theorem "[Věta 2.3 (Grupy řádu 4)](#theorem-2.3)"

    ### Věta 2.3 (Grupy řádu 4) {#theorem-2.3}

    Existují pouze dvě neizomorfní grupy řádu 4.<br><br>
    Neboli $\mathbb{Z}_4^+$ a Kleinova grupa jsou jediné grupy řádu 4 **až na izomorfismus**


<a id="def-2.4"></a>
!!! Definition "[Definice 2.4 (Symetrická grupa)](#def-2.4)"

    ### Definice 2.4 (Symetrická grupa) {#def-2.4}

    Symetrickou grupou množiny $\hat{n}$, neboli $\{1,2,3,\dots,n\}$ nazveme množinu všech permutací
    této množiny s operací skládání zobrazení a značíme ji $S_n$

<a id="exc-2.1"></a>
!!! example "[Příklad 2.1 (Připomenutí permutací)](#exc-2.1)"

    - Permutace je bijekce z množiny do stejné množiny, tedy v našem případě z $\hat{n}$ do $\hat{n}$
    - Permutace $\pi \in S_n$ se typicky zadávají výčtem hodnot: $\pi = (\pi(1), \pi(2), \pi(3), \pi(4), \pi(5)) \in S_5$
      - Např. $(1,2,4,3,5) \in S_5$ je permutace prohazující 3. a 4. prvek
    - Složením permutací $(1, 2, 4, 3, 5) \circ (2, 1, 3, 5, 4)$ je $(2, 1, 4, 5, 3)$
    - Skládání zobrazení je asociativní, permutace $(1, 2, 3, \dots, n)$ je neutrální prvek a inverzním prvkem je inverzní zobrazení – jedná se tedy skutečně o grupu. Řád $S_n$ je $n!$

<a id="def-2.5"></a>
!!! Definition "[Definice 2.5 (Grupy permutací)](#def-2.5)"
    
    ### Definice 2.5 (Grupy permutací) {#def-2.5}

    Podgrupy symetrické grupy $S_n$ nazýváme grupami permutací.

Například permutace $(1, 2, 4, 3, 5) \in S_5$ prohazující 3. a 4.prvek generuje podgrupu grupy S_5
obsahující dva prvky: $(1, 2, 4, 3, 5)$ a $(1, 2, 3, 4, 5)$
