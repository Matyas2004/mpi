!!! Definition "[Definice 5.4 (Diagnoalizovatelná matice)](#def-5.4)"

    ### Definice 5.4 (Diagnoalizovatelná matice) {#def-5.4}

    Nechť $\m{M} \in \mathbb{C}^{n,n}$. Matici $\m{M}$ nazýváme **diagonalizovatelnou**, pokud
    existují diagonální matice $\m{D} \in \mathbb{C}^{n,n}$ a regulární matice $\m{P} \in \mathbb{C}^{n,n}$
    splňující:

    $$\m{M} = \m{P}\m{D}\m{P}^{-1}$$

<a id="theorem-5.5"></a>
!!! Theorem "[Věta 5.5 (O matici $\mathbf{P}$)](#theorem-5.5)"

    ### Věta 5.5 (O matici P) {#theorem-5.5}

    Nechť $\m{M} \in \mathbb{C}^{n,n}$ je diagonalizovatelná, a platí tedy 
    $\m{M} = \m{P}\m{D}\m{P}^{-1}$, pak matice $\m{P}$ obsahuje ve sloupcích vlastní vektory matice $\m{M}$, 
    které tvoří bázi $\mathbb{C}^n$, a na diagonále matice $\m{D}$ jsou vlastní čísla matice $\m{M}$ (včetně násobností).

<a id="theorem-5.6"></a>
!!! Theorem "[Věta 5.6 (O mocnění diagonalizovatelných matic)](#theorem-5.6)"

    ### Věta 5.6 (O mocnění diagonalizovatelných matic) {#theorem-5.6}

    Nechť $\m{M} \in \mathbb{C}^{n,n}$ je diagonalizovatelná, a platí tedy 
    $\m{M} = \m{P}\m{D}\m{P}^{-1}$.

    Pak platí, že $\m{M}^k = \m{P}\m{D}^k\m{P}^{-1}$: vlastní čísla určují chování $\m{M}^k$ pro $k \to + \infty$. 
    Na tom stojí mocninná metoda.

??? Proof "Náznak důkazu věty 5.6"

    Matematickou indukcí:<br><br>

    Pro $k = 1$ platí triviálně  

    Pro $k > 1$ pak:

    $$
        \m{M}^k = \m{M} \cdot \m{M}^{k - 1} =^{\text{IP}} \m{M} \m{P}\m{D}^{k - 1}\m{P}^{-1} = 
        \m{P}\m{D}\m{P}^{-1} \m{P}\m{D}^{k - 1}\m{P}^{-1} = \m{P}\m{D}\m{D}^{k - 1}\m{P}^{-1} = \m{P}\m{D}^{k}\m{P}^{-1}
    $$

<a id="def-5.5"></a>
!!! Definition "[Definice 5.5 (Hermitovsky sdružená matice)](#def-5.5)"

    ### Definice 5.5 (Hermitovsky sdružená matice) {#def-5.5}

    Pro $\m{A} \in \mathbb{C}^{m,n}$ označujeme **komplexním sdružením matice** matici $\overline{\m{A}}$, kde každý
    prvek matice komplexně sdružíme.

    **Hermitovským sdružením matice** $\m{A}$ je pak matice $\m{A}^* \in \mathbb{C}^{n,m}$, pro kterou platí:

    $$\m{A}^* := \overline{\m{A}}^T$$

<a id="note-5.2"></a>
!!! Implication "[Poznámka 5.2 (Značení hermitovsky sdružené matice)](#note-5.2)"

    ### Poznámka 5.2 (Značení hermitovsky sdružené matice) {#note-5.2}

    Hermitovsky sdružená matice se častěji značí jako $\m{A}^\dagger$. Případně pak jako $\m{A}^H$

<a id="def-5.6"></a>
!!! Definition "[Definice 5.6 (Skalární součin)](#def-5.6)"

    ### Definice 5.6 (Skalární součin) {#def-5.6}

    Pro vektory $\m{x}, \m{y} \in \mathbb{C}^n$ zavádíme **skalární součin**:

    $$\m{x}^* \m{y} = \sum _{i=1} ^{n} = \overline{x_i}y_i$$

    tento skalární součin se typicky nazývá **standardní skalární součin**.

    Zároveň tedy platí: $\m{x}^*\m{x} = \|\m{x}\|_2^2$

<a id="def-5.7"></a>
!!! Definition "[Definice 5.7 (Další druhy matic)](#def-5.7)"

    ### Definice 5.7 (Další druhy matic) {#def-5.7}

     Nechť $\m{M} \in \mathbb{C}^{n,n}$. Matici $\m{M}$ nazýváme:

    - **normální**, pokud komutuje se svým hermitovským sdružením, tedy $\m{M}^* \m{M} = \m{M} \m{M}^*$
    - **hermitovskou**, pokud je svým hermitovským sdružením, tedy $\m{M}^* = \m{M}$
    - **symetrickou**, pokud platí $\m{M}^T = \m{M}$
    - **unitární**, pokud platí $\m{M}^* \m{M} = \m{E}$

<a id="theorem-5.7"></a>
!!! Theorem "[Věta 5.7 (O speciálních maticích)](#theorem-5.7)"

    ### Věta 5.7 (O speciálních maticích) {#theorem-5.7}

    Každá hermitovská matice je normální.

    Každá reálná symetrická matice je hermitovská.

    Normální matice jsou právě ty, které lze diagnoalizovat unitární maticí - tedy matice $\m{M} \in \mathbb{C}^{n,n}$,
    pro které existuje unitární matice $\m{U} \in \mathbb{C}^{n,n}$ a diagonální matice $\m{D} = \mathbb{C}^{n,n}$, že:

    $$\m{M} = \m{U} \m{D} \m{U}^*$$

    Vlastní vektory normální matice tvoří ortonormální bázi. (bázi vzájemně kolmých vektorů délky 1)
