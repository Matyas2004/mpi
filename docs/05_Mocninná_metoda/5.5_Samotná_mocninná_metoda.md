Připomenutí: V mocinné metodě hledáme v absolutní hodnotě největší (dominantní) vlastní číslo $\lambda_1$ matice $\m{M} \in \mathbb{C}^{n,n}$ a příslušný
vlastní vektor $\m{v}_1$

<a id="algo-5.1"></a>
!!! Algorithm "[Algoritmus 5.1 (Mocninná metoda)](#algo-5.1)"

    ### Algoritmus 5.1 (Mocninná metoda) {#algo-5.1}
    
    !!! Algorithm  "Vstup"
        Diagonalizovatelná matice $\m{M} \in \mathbb{C}^{n,n}$, pro jejíž vlastní čísla platí:

        $$|\lambda_1| > |\lambda_2| \ge \dots \ge |\lambda_n| $$

        Nesmí existovat jiné vlastní číslo se stejnou absolutní hodnotou jako $\lambda_1$

        Dále počáteční aproximace $\m{x}_0$, tolerance $\varepsilon$, maximální počet iterací $K$

    !!! Algorithm "Výstup"
        
        Dominantní vlastní číslo $\lambda_1$ a příslušný vlastní vektor $\m{v}_1$    

    !!! Algorithm "Algoritmus"
    
        Algoritmus **Mocninná metoda**(matice $\m{M}$)
        
        - $\m{y}_0 = \m{x}_0 / \| \m{x}_0 \|_2$
        - $\m{z}_0 = \m{M} \m{y}_0$
        - Pro $k = 0,1,\dots, K - 1$, opakuj:
            - $\m{y}_{k+1} = \m{z}_k / \| \m{z}_k \|_2$
            - $\m{z}_{k+1} = \m{M} \m{y}_{k+1}$
            - $\lambda^{(k+1)} = \m{y}^*_{k+1} \m{z}_{k+1}$ (Rayleighův podíl)
            - $\m{r}_{k+1} = \m{z}_{k+1} - \lambda^{(k+1)} \m{y}_{k+1}$
            - Pokud $\| \m{r}_{k+1} \|_2 < \varepsilon$, vrať $\lambda^{(k+1)}$ a $\m{y}_{k+1}$
        - Vrať "Nekonvergovalo po $K$ krocích"

??? Proof "Proč mocninná metoda konverguje"

    - Vlastní vektory tvoří bázi: z $\m{M} = \m{P}\m{D}\m{P}^{-1}$ plyne $\m{M}\m{P} = \m{P}\m{D}$, 
    tedy pro sloupce $\m{v}_i$ matice $\m{P}$ platí $\m{M}\m{v}_i = \lambda_i \m{v}_i$. Matice $\m{P}$ je regulární, 
    její sloupce jsou proto lineárně nezávislé a tvoří bázi $\mathbb{C}^n$. (K tomu potřebujeme diagonalizovatelnost.)

    - Rozložme $\m{x}_0 = \sum_{i=1}^{n} \alpha_i \m{v}_i$. Koeficienty $\alpha_i$ jsou souřadnice $\m{x}_0$ 
    v bázi vlastních vektorů: z $\m{x}_0 = \m{P}(\alpha_1, \dots, \alpha_n)^T$ je $\alpha_i$ právě $i$-tá složka 
    vektoru $\m{P}^{-1}\m{x}_0$. **Předpokládejme** $\alpha_1 \neq 0$. Pak
    
    $$
    \m{x}_k = \m{M}^k \m{x}_0 = \m{P}\m{D}^k \m{P}^{-1} \m{x}_0 = P(\lambda_1^k \alpha_1, \dots, \lambda_n^k \alpha_n)^T 
    = \sum_{i=1}^{n} \alpha_i \lambda_i^k \m{v}_i = \lambda_1^k \alpha_1 (\m{v}_1 + \m{e}_k),
    $$
    
    kde $\m{e}_k := \sum_{i=2}^{n} \frac{\alpha_i}{\alpha_1} \left(\frac{\lambda_i}{\lambda_1}\right)^k \m{v}_i$.
    
    - Všechny podíly $|\lambda_i/\lambda_1| \le q := |\lambda_2/\lambda_1| < 1$, proto $\|\m{e}_k\| = 
    \mathcal{O}(q^k) \to 0$: směr vektoru $\m{x}_k$ se blíží směru $\m{v}_1$, a to s chybou řádu $q^k$.

<a id="theorem-5.10"></a>
!!! Theorem "[Věta 5.10 (O rychlosti konvergence Mocninné metody)](#theorem-5.10)"

    ### Věta 5.10 (O rychlosti konvergence Mocninné metody) {#theorem-5.10}

    - Chyba směru je $\| \m{e}_k \| \le C\m{q}^k$, $q = |\lambda_2/\lambda_1|: 
    klesá geometricky, zhruba $q$-krát v každém kroku (v logaritmickém měřítku podél přímky). 
    Takové konvergenci se říká **lineární**.
    - Rayleighův podíl konverguje obecně také jako $q^k$
    - Pro normální matice Rayleigův podíl dokonce konverguje jako $q^{2k}$, důkaz je v [oficiálním handoutu](https://courses.fit.cvut.cz/NI-MPI/latex/lectures/czech/mi-mpi-prednaska-23-vlastni-cisla-handout.pdf)

- Ke zmenšení chyby $10^6$-krát je potřeba zhruba $\frac{\ln{10^{−6}}{\ln{q}} kroků: $49$ pro $q = 0.75$, 
$132$ pro $q = 0.9$ a $1375$ pro $q = 0.99$
- Je-li $|\lambda_2|$ blízko $|\lambda_1|$, tedy $q$ blízko 1, konvergence je pomalá
