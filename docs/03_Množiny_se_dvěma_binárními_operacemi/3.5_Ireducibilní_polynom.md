!!! Definition "[Definice 3.9 (Ireducibilní polynom)](#def-3.9)"

    ### Definice 3.9 (Ireducibilní polynom) {#def-3.9}

    Nechť $P(x) \in R[x]$ stupně **alespoň 1**. Řekneme, že $P(x)$ je **ireducibilní nad okruhem $R$**, jestliže pro 
    každé dva polynomy $A(x), B(x) \in R[x]$ platí:

    $$A(x) \cdot B(x) = P(x) \Rightarrow (\deg(A(x)) = 0 \text{ NEBO } \deg(B(x)) = 0)$$

Ireducibilní polynomy jsou definovány analogicky jako jsou prvočísla v množině přirozených celých čísel.

<a id="ex-3.4"></a>
!!! example "[Příklad 3.4 (Příklady ireducibilních_polynomů)](#ex-3.4)"

    ### Příklad 3.4 (Příklady ireducibilních_polynomů) {#ex-3.4}
 
    - $x$ je ireducibilní nad $\mathbb{Q}$
    - $x^2$ není ireducibilní nad $\mathbb{Q}$ –> $x^2 = x \cdot x$
    - $x^2 + 1$ je ireducibilní nad $\mathbb{Q}$
    - $x^2 + 1$ je ireducibilní i nad $\mathbb{R}$
    - $x^2 + 1$ ale **není** ireducibilní nad $\mathbb{C}$ –> $x^2 + 1 = (x+i)(x-i)$

<a id="def-3.10"></a>
!!! Definition "[Definice 3.10 (Möbiova funkce)](#def-3.10)"

    ### Definice 3.10 (Möbiova funkce) {#def-3.10}

    Möbiova funkce je definovaná pro přirozené $n$ takto:

    $$
    \mu(n) = \begin{cases} 
    1 & \text{pokud } n \text{ neobsahuje čtverec prvočísla a má sudý počet prvoč. faktorů,} \\ 
    -1 & \text{pokud } n \text{ neobsahuje čtverec prvočísla a má lichý počet prvoč. faktorů,} \\ 
    0 & \text{pokud } n \text{ obsahuje čtverec prvočísla.} 
    \end{cases}
    $$

<a id="theorem-3.10"></a>
!!! Theorem "[Věta 3.10 (O počtu ireducibilních polynomů)](#theorem-3.10)"

    ### Věta 3.10 (O počtu ireducibilních polynomů) {#theorem-3.10}

    Mějme přirozené $n > 1$ a prvočíslo $p$. Označme $N(p,n)$ počet [monických](3.4_Polynom_nad_okruhem.md#def-3.7)
    polynomů stupně $n$ ireducibilních nad $\mathbb{Z}_P$. Potom:

    $$N(p,n) = \frac{1}{n} \sum_{d \mid n} \mu(d) p^{\frac{n}{d}} \ge \frac{1}{n} \left( p^n - \sum_{q \mid n, \, q \text{ prvoč.}} p^{\frac{n}{q}} \right)$$

Poznat, jestli je daný polynom ireducibilní je snazší, než poznat jestli dané číslo je prvočíslo:  

Dokonce existují polynomiální algoritmy, které nejen rozhodnou o ireducibilitě, ale dokonce najdou
rozklad na ireducibilní polynomy (obdoba prvočíselného rozkladu).
